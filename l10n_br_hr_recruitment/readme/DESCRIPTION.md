Dados brasileiros do funcionário já no candidato (`hr.applicant`), para que o funcionário criado a
partir da candidatura nasça com o cadastro completo.

O candidato ganha os campos do `l10n_br_hr`: data de nascimento, nacionalidade, etnia, filiação,
CPF, RG, título de eleitor, certificado de reservista, PIS/PASEP, CNH e conta bancária. O
funcionário ganha campos para guardar os arquivos dos documentos (RG, CNH, título de eleitor,
reservista, comprovantes de endereço e de escolaridade, PIS), e o tipo de contrato ganha o regime.
