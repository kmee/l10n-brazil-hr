Formulário público para o candidato completar os próprios dados.

Quando um candidato é cadastrado, o módulo gera um token de acesso único e, com ele, o link de um
formulário no portal do site. O link é enviado ao candidato por e-mail (um botão na candidatura
facilita o envio), e ele preenche dados como conta bancária, etnia e dependentes, que ficam
gravados na candidatura.
