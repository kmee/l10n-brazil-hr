Importação dos feriados brasileiros para o calendário de feriados públicos da OCA
(`hr_holidays_public`).

O assistente gera os feriados de um intervalo de anos a partir das datas do `l10n_br_resource`:
os nacionais sempre, os estaduais quando o estado é informado e os municipais quando a cidade é
informada. Esses feriados são os que a apuração do ponto e o multiplicador de horas extras usam.
