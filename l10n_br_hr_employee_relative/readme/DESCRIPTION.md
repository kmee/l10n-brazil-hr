Estende os dependentes do funcionário (`hr_employee_relative`, OCA/hr) com os
dados que a folha e as obrigações trabalhistas brasileiras pedem:

- dependente para dedução do IRRF;
- dependente do salário-família;
- pensão alimentícia e valor de provisão;
- incapaz para o trabalho, com o comprovante de incapacidade;
- cobertura pelo plano de saúde do funcionário;
- documento do dependente anexado.

Os indicadores aparecem como colunas na lista de dependentes do funcionário.
