1. Abra um funcionário em *Funcionários* e vá à aba *Dependentes*.
2. Adicione o dependente (parentesco, nome, nascimento) e marque os indicadores
   que valem para ele: dependente para IRRF, salário-família, pensão
   alimentícia, incapaz para o trabalho e plano de saúde.
3. Informe o valor de provisão quando houver pensão ou provisão para o
   dependente.
4. As colunas *Incapaz para o trabalho*, *Plano de saúde*, *Valor de provisão*
   e os documentos ficam ocultas por padrão; ative-as no seletor de colunas da
   lista.

Com os dados de demonstração, abra *João Carlos da Silva* para ver dois
dependentes com IRRF, salário-família e plano de saúde.
